# RoundSoundMimic

Minimal WPF "Hello World" app to verify the toolchain.

## Build

1. Open the solution folder in Visual Studio or VS Code.
2. Restore and build the project.

## Run

Run the app from your IDE or from the build output.

## Configure

Enter your Jellyfin server URL, API key, and optional user id, then click "Save Config" and "Fetch Now Playing".
The config is stored in %AppData%\RoundSoundMimic\config.json.
